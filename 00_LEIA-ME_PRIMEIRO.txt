SMART ROUTINE SI — V4.1.0 ACADÊMICO, AZUL E LOCAL
==================================================

Esta versão é totalmente focada na graduação em Sistemas de Informação.
Ela gera aplicativo nativo para Android e Windows. Não é site, não abre dentro
do navegador, não usa nuvem e não exige conta externa.

O QUE A VERSÃO 4 ORGANIZA
- Semestres, matérias e conteúdos em uma hierarquia bem definida.
- Horário de segunda a domingo, inclusive os blocos 18:30–20:10 e 20:30–22:00.
- Resumos com várias imagens e PDF individual.
- Questões e simulados filtrados por matéria e conteúdo.
- Provas, trabalhos, projetos, atividades e apresentações.
- Flashcards com revisão espaçada e sessões de foco.
- Painel principal somente para consulta; cadastros no menu lateral.
- IDE acadêmica com projetos vinculados a semestre, matéria e conteúdo.
- Editor de Dart, Python, Java, JavaScript, TypeScript, C, C++, C#, Kotlin,
  PHP, SQL, HTML/CSS e JSON.

COMO FUNCIONA A IDE
- O editor, os projetos e os arquivos funcionam no Android e no Windows.
- O código fica no banco local e acompanha backup .mra e sincronização Wi-Fi.
- A execução acontece no PC com os compiladores instalados no próprio Windows.
- No celular, você edita e sincroniza; depois abre o mesmo projeto no PC para rodar.
- O aplicativo não envia código para a internet nem baixa compiladores sozinho.
- Consulte docs/IDE_ACADEMICA.md para preparar cada linguagem.

ANTES DE ATUALIZAR
1. Se já houver dados importantes, exporte um backup .mra no aplicativo atual.
2. Preserve a mesma chave de assinatura Android usada na versão instalada.
3. Extraia este ZIP sobre a pasta do projeto ou substitua o conteúdo do repositório.

PARA ENVIAR AO GITHUB PELO PC
1. Abra 07_SUBIR_GITHUB.bat.
2. Digite apenas a mensagem do commit — não cole a URL nesse campo.
3. Aguarde o processo terminar.
4. Abra Actions e baixe Smart-Routine-SI-Android e Smart-Routine-SI-Windows.

PARA ENVIAR PELO CELULAR
Também é possível usar o aplicativo/site do GitHub e carregar os arquivos,
mas enviar a pasta completa pelo BAT no PC é mais rápido e reduz o risco de
esquecer arquivos ocultos de configuração.
