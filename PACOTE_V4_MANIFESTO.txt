SMART ROUTINE SI 4.1.0+41
=========================

ESCOPO
Aplicativo acadêmico local para Sistemas de Informação, com a mesma base Flutter
para Android e Windows.

MÓDULOS VISÍVEIS
- Menu principal acadêmico
- Resumos com imagens e PDF
- Questões e simulados
- Avaliações
- Flashcards
- Foco/Pomodoro
- Organização de semestres, matérias, conteúdos e horários
- IDE acadêmica azul com projetos, vários arquivos e terminal integrado
- Dart, Python, Java, JavaScript, TypeScript, C, C++, C#, Kotlin, PHP, SQL,
  HTML/CSS e JSON
- Backup, PIN, conflitos e sincronização Wi-Fi

COMPATIBILIDADE PRESERVADA
- Banco SQLite local
- Backup/importação .mra
- Protocolo de sincronização PC ↔ celular
- ID do aplicativo Android
- Executável e identidade do instalador Windows
- Secrets e chave de assinatura MRA_*

VALIDAÇÃO DO PACOTE
- dart analyze: sem problemas
- compilação integral do código Flutter: concluída
- testes e builds Android/Windows configurados no GitHub Actions
- nenhum .db, .sqlite, .mra, .jks ou arquivo de senha incluído
